## 1. Executive Summary & Objective

The **Viral Hook Optimizer & Native X Poll Subsystem** elevates the quality, retention, and interaction rates of all standalone posts, threads, and polls generated by XBot personas.

According to the open-source X recommendation algorithm:
1. **Dwell Time** (pausing to read) is one of the highest weighted positive signals. The first 1–2 lines ("The Hook") determine whether a user stops scrolling or swipes past.
2. **Interactive Elements (Polls)** force active user clicks. A user voting on a poll counts as an active engagement signal, boosting algorithmic distribution to Out-of-Network users.

This subsystem provides:
- An automated **Multi-Hook Generator & Evaluator** that crafts 4 distinct hook archetypes and uses an AI judge to pick the highest-retention opening.
- A **Native X Poll Generator & Playwright Action** that crafts controversial/engaging niche questions and executes poll creation via browser automation.

## 3. Detailed Component Specifications

### 3.1 Hook Optimization Engine (`xbot/ai/hook_optimizer.py`)
- **Hook Archetypes**:
  1. `curiosity_gap`: "90% of developers get agent memory wrong. Here is the 1 pattern that actually scales:"
  2. `contrarian`: "Vector databases are the biggest trap in modern AI development."
  3. `framework_breakdown`: "We stress-tested 5 autonomous agent frameworks. Here are the 4 hard lessons:"
  4. `story_relatable`: "Last month, our first production bot got shadowbanned in 4 hours. What we learned:"
- **Hook Evaluator (`evaluate_hooks`)**:
  - Scores each hook on a 1–10 scale based on:
    - *Scroll-Stopping Power* (punchiness, intrigue)
    - *No AI Clichés* (zero phrases like "In this thread, we explore...", "Let's dive in", "In today's fast-paced world")
    - *Brevity* (<140 characters before line break)
  - Reconstructs the full tweet with the winning hook and clean dwell formatting (micro-spacing).

### 3.2 Poll Generation Engine (`xbot/ai/poll_generator.py`)
- **Pydantic Model**:
  ```python
  class GeneratedPoll(BaseModel):
      question: str = Field(..., max_length=200, description="Engaging poll question")
      options: list[str] = Field(..., min_length=2, max_length=4, description="2 to 4 options, each <= 25 chars")
      duration_days: int = Field(default=1, ge=1, le=7, description="Poll duration in days")
      context_hook: str | None = Field(default=None, description="Optional introductory context line")
  ```
- Generates niche-relevant, polarizing, or curiosity-inducing questions in the persona's voice.

### 3.3 Native X Poll Browser Action (`xbot/browser/actions/poll_action.py`)
- Extends `BaseAction`.
- Class `CreatePoll`:
  - Opens compose modal or goes to `https://x.com/compose/post`.
  - Clicks the native Poll icon (`[data-testid="pollButton"]` or `[aria-label="Add poll"]`).
  - Types the main question / context.
  - Types each option into option input fields (`[name="Choice1"]`, `[name="Choice2"]`, etc.).
  - If 3 or 4 options, clicks `[aria-label="Add choice"]` (`[data-testid="addChoice"]`).
  - Sets duration if dropdown is accessible.
  - Clicks Tweet/Post button (`[data-testid="tweetButton"]`).
  - Returns `True` on success with screenshot on failure.
